# Akev Scoop bucket

[Scoop](https://scoop.sh) bucket for [Akev](https://akev.dev), the open-source HTTP(S)
debugging proxy.

## Install

```powershell
scoop bucket add akev https://github.com/akevdev/scoop-bucket
scoop install akev/akev
```

Then run `akev`: it starts the proxy and opens the web UI in your browser. Works on x64 and
arm64 Windows.

The desktop app (with its own window and installer) is on
[winget](https://github.com/microsoft/winget-pkgs) and the
[download page](https://akev.dev/download).

## Update

```powershell
scoop update akev
```

## About this bucket

`bucket/akev.json` is generated by Akev's release workflow and copied here automatically for
each release after its checksums are verified against the release's signed `SHA256SUMS`.
Every change is tested on x64 and arm64 Windows.

Issues: <https://github.com/akevdev/akev/issues>
